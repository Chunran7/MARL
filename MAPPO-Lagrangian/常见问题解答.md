## 运行和配置问题

### Q5: 如何选择合适的异步策略？
**A:** 根据你的场景选择：

| 场景 | 推荐策略 | 原因 |
|------|----------|------|
| 智能体重要性差异明显 | `hierarchical` | 稳定可靠，理论保证强 |
| 动态环境，重要性变化 | `importance` | 自适应能力强，效果最好 |
| 需要稳定收敛 | `progressive` | 平衡效果与效率 |
| 新手用户 | `hierarchical` | 最容易调参，最稳定 |

### Q6: 如何设置合适的selection_ratio？
**A:** 参考以下建议：
```bash
# 保守设置 (稳定但可能较慢)
--selection_ratio 0.7

# 平衡设置 (推荐)
--selection_ratio 0.5

# 激进设置 (快速但可能不稳定)
--selection_ratio 0.3

# 动态调整 (progressive模式)
--min_selection_ratio 0.3 --max_selection_ratio 0.8
```

### Q7: 不同环境的推荐配置是什么？
**A:** 环境特定配置：

**Ant-v2 (推荐新手):**
```bash
python train_mujoco_async.py \
    --scenario Ant-v2 \
    --agent_conf 2x4 \
    --safety_bound 0.2 \
    --async_mode hierarchical \
    --selection_ratio 0.5
```

**HalfCheetah-v2:**
```bash
python train_mujoco_async.py \
    --scenario HalfCheetah-v2 \
    --agent_conf 2x3 \
    --safety_bound 5.0 \
    --async_mode importance \
    --selection_ratio 0.6
```

**Humanoid-v2 (需要更多资源):**
```bash
python train_mujoco_async.py \
    --scenario Humanoid-v2 \
    --agent_conf 2x17 \
    --safety_bound 0.5 \
    --async_mode progressive \
    --min_selection_ratio 0.3 \
    --max_selection_ratio 0.8
```

### Q8: 如何调整训练速度？

**高性能机器:**

```bash
--n_training_threads 8 \
```

**普通机器:**

```bash
--num_mini_batch 40
```

**低配置机器:**
```bash
--n_training_threads 2 \
--n_rollout_threads 8 \
--num_mini_batch 20
```

## 性能和效果问题

### Q9: 训练效果不如预期怎么办？
**A:** 尝试以下调优策略：

1. **增加选择比例:**
```bash
--selection_ratio 0.7  # 从0.5增加到0.7
```

2. **调整学习率:**
```bash
--lr 5e-4  # 从默认3e-4增加
```

3. **增加训练步数:**
```bash
--num_env_steps 3000000  # 从1M增加到3M
```

4. **尝试不同异步策略:**
```bash
--async_mode importance  # 如果之前用hierarchical
```

### Q10: 训练速度太慢怎么办？
**A:** 性能优化建议：

1. **减少选择比例:**
```bash
--selection_ratio 0.3  # 更激进的异步
```

2. **调整并行参数:**
```bash
--n_rollout_threads 32  # 增加采样线程
--num_mini_batch 80     # 增加批次大小
```

3. **使用GPU加速:**
```bash
--cuda --cuda_deterministic
```

4. **减少日志频率:**
```bash
--log_interval 100      # 从10增加到100
--eval_interval 250     # 从25增加到250
```

### Q11: 内存不足怎么办？
**A:** 内存优化策略：

1. **减少并行线程:**
```bash
--n_rollout_threads 8   # 减少采样线程
--num_mini_batch 20     # 减少批次大小
```

2. **缩短episode长度:**
```bash
--episode_length 500    # 从1000减少到500
```

3. **使用更小的网络:**
```bash
--hidden_size 128       # 从默认256减少
```

### Q12: 如何判断训练是否正常？
**A:** 观察以下指标：

1. **奖励趋势:** 应该总体上升
```bash
grep "average_episode_rewards" logs/*.log | tail -10
```

2. **安全成本:** 应该在约束范围内
```bash
grep "average_episode_costs" logs/*.log | tail -10
```

3. **通信效率:** 应该比原算法高
```bash
grep "communication_efficiency" logs/*.log | tail -10
```

4. **训练稳定性:** 不应该有大幅波动

## 错误和调试问题

### Q13: 出现CUDA错误怎么办？
**A:** CUDA问题排查：

1. **检查CUDA可用性:**
```bash
python -c "import torch; print(torch.cuda.is_available())"
nvidia-smi
```

2. **如果CUDA不可用，使用CPU:**
```bash
# 移除 --cuda 参数
python train_mujoco_async.py --scenario Ant-v2  # 不加--cuda
```

3. **CUDA内存不足:**
```bash
--num_mini_batch 20     # 减少批次大小
--n_rollout_threads 8   # 减少线程数
```

### Q14: 出现"No module named"错误
**A:** 模块导入问题：

1. **重新安装项目:**
```bash
cd mappo_lagrangian
pip install -e .
```

2. **检查Python路径:**
```bash
python -c "import sys; print(sys.path)"
export PYTHONPATH="${PYTHONPATH}:/path/to/your/project"
```

3. **检查虚拟环境:**
```bash
which python
conda list | grep mappo
```

### Q15: 训练中断或崩溃怎么办？
**A:** 故障恢复策略：

1. **启用自动保存:**
```bash
--save_interval 100     # 每100轮保存一次
```

2. **从检查点恢复:**
```bash
--model_dir results/your_experiment/models
```

3. **使用调试模式:**
```bash
--log_level DEBUG
python -u train_mujoco_async.py ... 2>&1 | tee debug.log
```

```bash

    python train_mujoco_async.py --seed $seed --async_mode hierarchical

    python train_mujoco_async.py --seed $seed --async_mode progressive
done
```

2. **控制变量:**
```bash
# 只改变异步策略，其他参数保持一致

--lr 3e-4 \
--safety_bound 0.2
```

3. **使用批量实验脚本:**
```bash
./run_async_experiments.sh
```

### Q18: 如何分析实验结果？
**A:** 结果分析方法：

1. **查看训练曲线:**
```bash
tensorboard --logdir=results --port=6006
```

2. **统计最终性能:**
```bash
python -c "
import pandas as pd
import glob

for f in glob.glob('results/*/logs/progress.txt'):
    df = pd.read_csv(f)
    print(f'{f}: Reward={df[\"average_episode_rewards\"].iloc[-1]:.2f}, Cost={df[\"average_episode_costs\"].iloc[-1]:.2f}')
"
```

3. **计算统计显著性:**
```bash
python -c "
import numpy as np
from scipy import stats

# 假设你有多个种子的结果
hierarchical_rewards = [100, 102, 98, 105, 99]
importance_rewards = [108, 110, 106, 112, 107]

t_stat, p_value = stats.ttest_ind(hierarchical_rewards, importance_rewards)
print(f'T-test p-value: {p_value:.4f}')
"
```
