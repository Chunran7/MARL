# 简单使用说明

## 🎯 保持原来的使用方式

你的使用方式完全不变！只需要简单修改一个配置就能使用异步训练。

### 原来的使用方式 (完全不变)

```bash
# 1. 激活环境
conda activate macpo

# 2. 安装项目
cd MAPPO-Lagrangian
pip install -e .

# 3. 运行训练 (和以前一样)
./mappo_lagrangian/scripts/train_mujoco.sh
```

### 🚀 启用异步训练 (只需改一行)

打开 `mappo_lagrangian/scripts/train_mujoco.sh` 文件，找到这一行：

```bash
use_async=true                    # 改成 true 启用异步训练
```

**就这么简单！** 其他什么都不用改。

### 🔧 可选配置 (如果你想调整)

在同一个文件中，你还可以调整这些设置：

```bash
async_mode="hierarchical"         # 异步策略 (推荐用这个)
selection_ratio=0.5               # 选择比例 (0.5 是最稳定的)
```

### 📊 三种异步策略选择

| 策略 | 设置值 | 特点 | 什么时候用 |
|------|--------|------|------------|
| **hierarchical** | `async_mode="hierarchical"` | 最稳定 | **推荐新手使用** |
| **importance** | `async_mode="importance"` | 效果最好 | 想要最好效果时 |
| **progressive** | `async_mode="progressive"` | 平衡 | 需要稳定收敛时 |

### 🎯 推荐设置 (最简单)

```bash
use_async=true                    # 启用异步训练
async_mode="hierarchical"         # 使用最稳定的策略
selection_ratio=0.5               # 使用平衡的选择比例
```

### ✅ 预期效果

使用异步训练后，你会看到：
- 🚀 训练速度快 30-50%
- 📉 显存/内存使用更少
- 🎯 效果和原来差不多或更好

### 🔄 如何切换回原来的训练

如果你想用回原来的训练方式，只需要改一行：

```bash
use_async=false                   # 改成 false 就用回原来的方式
```

## 🆘 遇到问题？

### 常见问题

**Q: 运行出错了怎么办？**
A: 先试试把 `use_async=false` 改回原来的方式，确认环境没问题。

**Q: 效果不好怎么办？**
A: 试试调整 `selection_ratio=0.7` (更保守) 或 `selection_ratio=0.3` (更激进)

**Q: 想了解更多技术细节？**
A: 可以看 `README_async.md` 文件
