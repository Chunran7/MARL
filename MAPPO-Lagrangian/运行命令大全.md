## 三种异步策略

### 1. 分层异步更新 (Hierarchical)
```bash
# 基础配置
python train_mujoco_async.py \
    --async_mode hierarchical \
    --selection_ratio 0.5 \
    --scenario Ant-v2 \
    --agent_conf 2x4

# 高选择比例 (更保守)
python train_mujoco_async.py \
    --async_mode hierarchical \
    --selection_ratio 0.7 \
    --scenario Ant-v2 \
    --agent_conf 2x4

# 低选择比例 (更激进)
python train_mujoco_async.py \
    --async_mode hierarchical \
    --selection_ratio 0.3 \
    --scenario Ant-v2 \
    --agent_conf 2x4
```

### 2. 重要性采样异步更新 (Importance Sampling)
```bash
# 基础配置
python train_mujoco_async.py \
    --async_mode importance \
    --selection_ratio 0.6 \
    --scenario HalfCheetah-v2 \
    --agent_conf 2x3

# 动态重要性权重
python train_mujoco_async.py \
    --async_mode importance \
    --selection_ratio 0.6 \
    --importance_weight_decay 0.95 \
    --scenario HalfCheetah-v2 \
    --agent_conf 2x3

# 高重要性阈值
python train_mujoco_async.py \
    --async_mode importance \
    --selection_ratio 0.8 \
    --importance_threshold 0.1 \
    --scenario HalfCheetah-v2 \
    --agent_conf 2x3
```

### 3. 渐进式异步更新 (Progressive)
```bash
# 基础配置
python train_mujoco_async.py \
    --async_mode progressive \
    --min_selection_ratio 0.3 \
    --max_selection_ratio 0.8 \
    --scenario Humanoid-v2 \
    --agent_conf 2x17

# 快速渐进
python train_mujoco_async.py \
    --async_mode progressive \
    --min_selection_ratio 0.2 \
    --max_selection_ratio 0.9 \
    --progressive_steps 500000 \
    --scenario Humanoid-v2 \
    --agent_conf 2x17

# 慢速渐进
python train_mujoco_async.py \
    --async_mode progressive \
    --min_selection_ratio 0.4 \
    --max_selection_ratio 0.7 \
    --progressive_steps 1500000 \
    --scenario Humanoid-v2 \
    --agent_conf 2x17
```

## 批量实验命令

### 使用shell脚本运行
```bash
# 给脚本执行权限
chmod +x train_mujoco_async.sh
chmod +x run_async_experiments.sh

# 运行单个异步策略
./train_mujoco_async.sh

# 运行所有策略对比实验
./run_async_experiments.sh

# 后台运行实验
nohup ./run_async_experiments.sh > experiments.log 2>&1 &
```

### 并行运行多个实验
```bash
# 并行运行不同环境
python train_mujoco_async.py --scenario Ant-v2 --async_mode hierarchical --seed 1 &
python train_mujoco_async.py --scenario HalfCheetah-v2 --async_mode importance --seed 1 &
python train_mujoco_async.py --scenario Humanoid-v2 --async_mode progressive --seed 1 &

# 等待所有任务完成
wait
```

### 循环运行不同种子
```bash
# 运行多个种子
for seed in 1 2 3 4 5; do
    python train_mujoco_async.py \
        --scenario Ant-v2 \
        --async_mode hierarchical \
        --selection_ratio 0.5 \
        --seed $seed \
        --experiment_name "hierarchical_seed_${seed}" &
done
wait
```

## 🚨 重要提示

1. **内存管理**: 大型环境(如Humanoid)需要调整`--num_mini_batch`和`--n_rollout_threads`
2. **GPU使用**: 添加`--cuda`参数启用GPU加速
3. **实验管理**: 使用`--experiment_name`区分不同实验
4. **日志级别**: 生产环境使用`INFO`，调试时使用`DEBUG`
5. **种子设置**: 使用`--seed`确保实验可重复

选择合适的命令组合，开始你的异步训练实验吧！🚀
