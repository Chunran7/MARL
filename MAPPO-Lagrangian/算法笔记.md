## MAPPO-Lagrangian算法调用逻辑完整流程

### 1. 算法启动入口
- **Shell脚本启动**：<mcfile name="train_mujoco.sh" path="train_mujoco.sh"></mcfile>
  - 根据 `use_async` 参数选择执行模式
  - 异步模式：调用 `train_mujoco_async.py`
  - 同步模式：调用 `train_mujoco.py`

### 2. 环境初始化和配置加载
- **参数解析**：通过 `get_config()` 解析命令行参数和配置文件
- **环境创建**：初始化Mujoco环境，设置多智能体配置
- **设备配置**：设置CUDA/CPU设备，配置随机种子
- **WandB集成**：初始化实验跟踪和日志记录

### 3. Runner类初始化
- **同步模式**：实例化 `MujocoRunner_mappo_lagr`
- **异步模式**：实例化 `AsyncMujocoRunner_mappo_lagr`
- **组件创建**：
  - 策略网络（Actor-Critic）
  - 价值函数网络（奖励和成本）
  - 拉格朗日乘子
  - 经验缓冲区
  - 训练器（Trainer）

### 4. 主训练循环 `run()` 方法
```
for episode in range(total_episodes):
    1. warmup() - 预热阶段
    2. for step in range(episode_length):
        - collect() - 数据收集
        - insert() - 数据插入缓冲区
    3. compute() - 计算回报和优势函数
    4. train() - 执行训练更新
    5. 日志记录和模型保存
```

### 5. 数据收集 `collect()` 流程
- **环境交互**：智能体与环境交互获取观测
- **动作选择**：通过策略网络选择动作
- **环境步进**：执行动作，获取奖励、成本、下一状态
- **数据存储**：将经验存储到缓冲区

### 6. 训练更新 `train()` 和算法3执行
- **同步训练**（<mcfile name="base_runner_mappo_lagr.py" path="base_runner_mappo_lagr.py"></mcfile>）：
  ```
  1. 初始化重要性采样因子
  2. 随机智能体更新顺序
  3. for each agent:
      - 计算旧策略动作对数概率
      - 调用 trainer.train() 执行PPO更新
      - 计算新策略动作对数概率
      - 更新重要性采样因子
  ```

- **核心算法3实现**（<mcfile name="r_mappo_lagr.py" path="r_mappo_lagr.py"></mcfile>）：
  ```
  1. 计算奖励和成本优势函数
  2. 混合优势函数计算
  3. PPO裁剪目标优化
  4. 策略网络更新
  5. 拉格朗日乘子更新
  6. 价值函数更新
  ```

### 7. 异步训练调用逻辑差异
- **分层异步**（`hierarchical`）：
  - 将智能体分组
  - 组内同步，组间异步更新

- **重要性采样异步**（`importance`）：
  - 根据智能体重要性进行采样
  - 选中的智能体进行完整更新
  - 未选中的智能体进行轻量级价值函数更新

- **渐进式异步**（`progressive`）：
  - 按预定义顺序逐步更新智能体
  - 支持动态调整更新频率
