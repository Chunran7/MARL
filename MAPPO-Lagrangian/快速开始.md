# 异步MAPPO-Lagrangian 快速开始指南

## 🚀 5分钟快速开始

### 1. 环境准备
```bash
# 激活conda环境
conda activate macpo

# 进入项目目录
cd /path/to/Multi-Agent-Constrained-Policy-Optimisation/MAPPO-Lagrangian

# 验证安装
python -c "import mappo_lagrangian; print('✅ 项目安装成功')"
```

### 2. 快速测试
```bash
# 运行快速测试 (模拟模式)
python test_async_training.py
# 选择 1 (模拟测试)
```

### 3. 开始训练

#### 方式一：直接运行 (推荐新手)
```bash
# 分层异步训练 (最稳定)
python train_mujoco_async.py \
    --env_name mujoco \
    --scenario Ant-v2 \
    --agent_conf 2x4 \
    --async_mode hierarchical \
    --selection_ratio 0.5 \
    --num_env_steps 1000000
```

#### 方式二：使用脚本 (推荐批量实验)
```bash
# 给脚本执行权限
chmod +x train_mujoco_async.sh

# 编辑配置 (可选)
nano train_mujoco_async.sh

# 运行训练
./train_mujoco_async.sh
```

### 4. 监控训练
```bash
# 查看GPU使用
nvidia-smi

# 查看训练进度
tail -f results/*/logs/progress.txt

# 查看详细日志
tail -f logs/async_experiments/*.log
```

## 📊 三种异步策略对比

| 策略 | 特点 | 适用场景 | 推荐参数 |
|------|------|----------|----------|
| **分层异步** | 稳定可靠 | 智能体重要性差异明显 | `--selection_ratio 0.5` |
| **重要性采样** | 效果最好 | 动态环境，智能体重要性变化 | `--selection_ratio 0.6` |
| **渐进式** | 平衡效果与效率 | 需要稳定收敛的场景 | `--min_selection_ratio 0.3` |


## 🔧 常用参数

### 基础参数
```bash
--async_mode hierarchical        # 异步策略: hierarchical/importance/progressive
--selection_ratio 0.5           # 智能体选择比例 (0.1-1.0)
--num_env_steps 1000000         # 训练步数 (建议1M-10M)
--safety_bound 0.2              # 安全约束 (Ant:0.2, HalfCheetah:5.0)
--seed 50                       # 随机种子
```

### 性能调优
```bash
--n_training_threads 4          # 训练线程数 (根据CPU核数调整)
--n_rollout_threads 16          # 采样线程数 (根据内存调整)
--num_mini_batch 40             # 批次大小 (内存不足时减小)
```
